# Generador de la identidad

Todo sale de aquí, sin tocar el sitio. `marcas.mjs` contiene el dibujo y `datos.mjs`, los textos y la evaluación.

```bash
npm ci --ignore-scripts
npm run generar
```

Las capturas necesitan el sitio en `http://localhost:4321` y Google Chrome. Sustituyen el logotipo y la paleta solo en memoria.

Las fuentes de `fuentes/` tienen licencia SIL OFL 1.1, con su texto al lado.
